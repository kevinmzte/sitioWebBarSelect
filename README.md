# Bar Select – Sitio Web de Menú para Restaurante

Este proyecto consiste en el desarrollo de un **sitio web de prueba para un negocio gastronómico**, diseñado para mostrar de manera clara el menú de comidas y bebidas, junto con información del local y canales de contacto.

La página presenta una **interfaz moderna y minimalista**, enfocada en la experiencia del usuario, permitiendo navegar fácilmente entre secciones como catálogo de platos, horarios de atención, historia del restaurante y contacto.

El sitio también incluye funcionalidades interactivas como **menú expandible, visualización ampliada de imágenes de platos y un chat integrado para consultas o pedidos**, con opción de redirigir a WhatsApp.

## Características

- Menú de navegación responsive
- Catálogo de comidas con menú expandible
- Visualización de imágenes de platos en tamaño ampliado (lightbox)
- Sección de horarios del local
- Sección de historia del restaurante
- Chat flotante para consultas y pedidos
- Acceso directo a WhatsApp
- Diseño moderno orientado a negocios gastronómicos

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## Objetivo del proyecto

Este proyecto fue desarrollado como **práctica de desarrollo frontend**, con el objetivo de mejorar habilidades en:

- Maquetación web
- Diseño de interfaces
- Organización de contenido para sitios comerciales
- Implementación de interacciones con JavaScript
